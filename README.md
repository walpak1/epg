EPG Grabber

Automated EPG (Electronic Programme Guide) grabber that collects TV programme schedules and generates XMLTV-compatible files.

The repository is designed specifically for EPG data collection and processing.

Purpose

This repository is intended for:

EPG data grabbing
EPG processing
XMLTV generation
Automated EPG updates
Personal EPG data management

This repository does not provide TV streams or an IPTV player.
